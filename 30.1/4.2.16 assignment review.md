### 1. Membership Operators (`in`, `not in`)

These operators check for the existence of an item without needing a manual loop.

* `in` returns `True` if a value exists in a sequence.
* `not in` returns `True` if a value does **not** exist in a sequence.
* `==` checks if two values are equal.

```python
# Check if an item is inside a list:
fruits = ["apple", "banana", "cherry"]

if "banana" in fruits:
    # Executes because "banana" is in the list
    pass

if "orange" not in fruits:
    # Executes because "orange" is missing
    pass

```

---

### 2. Mutating Patterns (In-Place Changes)

Use a `while` loop when deleting items from the original list. If you use a `for` loop, you will skip items because the list "shrinks" while you are moving through it.

```python
# Pattern for safely removing matching items in-place:
currentIndex = 0

while currentIndex < len(L):
    if L[currentIndex] == condition:
        # Removing an item shifts everything after it to the left
        L.pop(currentIndex)
        # DO NOT increment currentIndex here!
    else:
        # Only step forward when no item was removed
        currentIndex += 1

```

---

### 3. Non-Mutating Patterns (Creating New Lists)

This is generally safer. We create an empty accumulator list and fill it using a `for` loop, leaving the original data untouched.

```python
# Pattern for building a filtered new list:
resultList = []

for item in L:
    if condition:
        resultList.append(item)

# resultList holds the new data; L remains unchanged

```

### 4. Slicing (`L[start:stop]`)

Slicing creates a **new copy** of a section of a list.

* `L[:i]` gets everything **before** index `i` (the prefix).
* `L[i:]` gets everything from index `i` **to the end** (the suffix).

```python
L = [10, 20, 30, 40, 50]
i = 2

# Prefix slice (items at index 0 up to, but excluding, i)
prefix = L[:i]  # [10, 20]

# Rotating a list by joining suffix and prefix
rotated = L[i:] + L[:i]  # [30, 40, 50] + [10, 20] -> [30, 40, 50, 10, 20]

```

### 5. Modulo & Math (`%`, `//`)

* `%` (Modulo) gives the **remainder** of division.
* `//` (Floor Division) gives the **whole number**.

```python
# Check if a number is even:
isEven = (n % 2 == 0)

# Find the middle index of a collection:
midIndex = len(L) // 2

```

---

### 6. Negative Indexing

Python lets you count from the end of a list using negative numbers. This is great for grabbing recent values in a sequence!

```python
# -1 is always the last item, -2 is the second-to-last
lastItem = items[-1]
secondToLast = items[-2]

# Calculate the next term in a sequence from the last two values:
nextTerm = items[-1] + items[-2]

```

### 7. List Operations Reference

| Operation | Type | Syntax Example | Purpose |
| --- | --- | --- | --- |
| **Append** | Mutating | `myList.append(val)` | Adds an item to the end of the existing list. |
| **Pop** | Mutating | `myList.pop(i)` | Removes the item at index `i` and shifts remaining items left. |
| **Swap** | Mutating | `L[i], L[j] = L[j], L[i]` | Swaps two values in place without a third variable. |
| **Combine** | Non-Mutating | `newList = listA + listB` | Creates a new list by joining two existing lists. |
| **Repeat** | Non-Mutating | `zeros = [0] * 5` | Creates a new repeated list `[0, 0, 0, 0, 0]`. |
