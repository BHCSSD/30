# Java (Processing) vs. JavaScript (p5.js) Cheat Sheet

### 1. Variables and Types

| Feature | Processing (Java) | p5.js (JavaScript) |
| :--- | :--- | :--- |
| **Integers/Floats** | `int x = 5;` / `float y = 5.5;` | `let x = 5;` / `let y = 5.5;` |
| **Vectors** | `PVector pos;` | `let pos;` |
| **Booleans** | `boolean isRunning = true;` | `let isRunning = true;` |
| **Arrays (Fixed)** | `float[] values = new float[10];` | `let values = new Array(10);` |
| **Arrays (Dynamic)**| `ArrayList<Particle> p;` | `let p = [];` |


---

## Lists: ArrayList (Java) vs. Arrays (JS)

In Processing, you use an `ArrayList` to store a collection of objects, like particles, because it allows you to add and remove items dynamically.

### 1. Declaration and Initialization
In Java, you must tell the computer exactly what is inside the list. In JavaScript, a list can hold anything.

* **Processing (Java):** `ArrayList<Particle> particles = new ArrayList<Particle>();`
* **p5.js (JavaScript):** `let particles = [];`

---

### 2. Common Operations Table

| Action | Processing (`ArrayList`) | p5.js (`Array`) |
| :--- | :--- | :--- |
| **Add item** | `particles.add(new Particle());` | `particles.push(new Particle());` |
| **Get item** | `Particle p = particles.get(i);` | `let p = particles[i];` |
| **Get size** | `particles.size();` | `particles.length;` |
| **Remove item** | `particles.remove(i);` | `particles.splice(i, 1);` |
| **Clear all** | `particles.clear();` | `particles = [];` |

# Understanding Vectors

A **Vector** is a container for numbers representing **direction** and **magnitude** (size). Think of it as an instruction on how to move rather than a fixed point.

### Key Properties:

  * **Magnitude:** The length of the vector (`v.mag()`).
  * **Heading:** The angle the vector is pointing (`v.heading()`).

### Essential Operations:

1.  **Addition (Movement):** Position_{new} = Position_{old} + Velocity
      * `this.pos.add(this.vel);`
2.  **Subtraction (Targeting):** Direction = Target - Current
      * `let diff = p5.Vector.sub(target, this.pos);`
3.  **Normalization (Standardizing):** Shrinks the magnitude to 1 to get a direction vector.
      * `v.normalize();`
4.  **Scaling:** Use `v.mult(0.5);` to adjust speed/force.
