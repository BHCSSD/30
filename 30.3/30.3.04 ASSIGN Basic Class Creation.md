> [!NOTE]
> ## INFODUMP: The Splice Glitch
> When you use `myArray.splice(i, 1)`, you are removing the item at index `i`. 
> 
> **The Problem:**
> Right after the splice, every item to the right **shifts left** by one position. 
> * When looping forward with `i++`, the loop counter moves to the next number
>     * Since the items shifted left, the "new" item at index `i` is skipped entirely
> 
> This causes "ghost" objects that never get deleted or flickering animations where every other collision is ignored.
> ## **Reverse Loop**
> To avoid the glitch, loop **backwards**. By starting at the end of the list and moving toward index 0, removing an item only shifts the items we have *already* checked.
> 
> ### **Reverse Loop**
> ```javascript
> 
> for (let i = bubbles.length - 1; i >= 0; i--) {
>   if (bubbles[i].isDead) {
>     bubbles.splice(i, 1); // Everything shifts, but we are moving left anyway
>   }
> }
> ```
> 1.  **The Trigger Condition**
>     * Inside your class, you need a way to know when an object is "done." 
>     * **Common triggers:** `this.y > height`, `this.lifespan < 0`, or `dist(...) < radius`.
> 
> 2.  **The Kill Switch Method**
>     * Add a method to your class that returns `true` or `false`.
>     ```javascript
>     class Bubble {
>       //constructor and move methods would be here
>       
>       isOffScreen() {
>         return (this.y < 0); // Returns true if it's gone
>       }
>     }
>     ```
> 
> 3.  **The Clean-up Crew**
>     * In your `draw()` function, use the **Reverse Loop** to check that condition and splice.
> 
> 4.  **Verify with a Counter**
>     * Add `text(myArray.length, 20, 20)` to your canvas. 
>     * If you see the number go up when you create objects, but **never go down**, your splice logic is broken
