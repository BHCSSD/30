# 30.3.07 LESSON Encapsulation with Private Class.md

## 1. The Concept: Public vs. Private
By default, JavaScript class properties are **public**. 
* This means any part of your sketch can modify them.
* **Private features** allow you to "lock" parts of your object, making them accessible only from *inside* the class itself.

### Key Differences
| Feature | Public (`this.x`) | Private (`this.#x`) |
| :--- | :--- | :--- |
| **Access** | Anywhere in the sketch. | Only inside the `{ class }`. |
| **Visual Aid** | Shows up in autocomplete. | Hidden from external view. |
| **Risk** | Can be broken by accident. | Protected and secure. |



---

## 2. Why Use Private Features in Creative Coding?
When building complex systems (like particle engines or game characters), private features help you:

* **Prevent Accidental Overwrites:** You don't want a random function to accidentally set your `particle.velocity` to a String.
* **Encapsulation:** Keep the "messy" math inside the class and only show "clean" methods like `.update()` or `.display()` to the rest of your sketch.
* **Stability:** If you change how an internal calculation works, you don't have to rewrite your entire `draw()` loop.

---

## 3. Syntax
To use private features, you must follow two strict rules:

1.  **The Hash Prefix:** Use the `#` symbol before the variable or method name
2.  **Explicit Declaration:** You **must** declare private variables at the very top of the class, before the `constructor`


```javascript
class SecretCircle {
  // 1.MANDATORY: Declare private fields at the top
  #angle = 0;
  #speed;

  constructor(x, y, speed) {
    this.x = x; //Public: anyone can move the circle
    this.y = y; //Public
    this.#speed = speed; //Private: the speed is locked in
  }

  //A public method to run the object
  run() {
    this.#calculate(); 
    this.#drawMe();
  }

  // 2.Private Method: Internal logic only
  #calculate() {
    this.#angle += this.#speed;
  }

  #drawMe() {
    //use the private #angle to determine size
    let diameter = map(sin(this.#angle), -1, 1, 20, 100);
    
    fill(150, 100, 255);
    noStroke();
    circle(this.x, this.y, diameter);
  }
}

let myObject;

function setup() {
  createCanvas(400, 400);
  myObject = new SecretCircle(200, 200, 0.05);
}

function draw() {
  background(20);


  myObject.run()   // Yay, this works perfectly

  // This would cause a CRASH (Syntax Error):
  // console.log(myObject.#angle); 
  
  // This works (changing public data):
  myObject.x = mouseX; 
}
```

* [ ] Use `#variableName` to make a property private.
* [ ] Always declare `#variables` at the top of the class.
* [ ] Use private variables for internal math, timers, or sensitive states.
* [ ] Use public methods (like `update()`) to allow the rest of your p5.js sketch to interact with the class safely.
