## 2. Step-by-Step Implementation Guide

### Step 2: Build the `Ball` Class & Wall Physics

**TODO:**

1. Create a `Ball.js` file.
2. Define a `Ball` class with position `pos` and velocity `vel` (vector).

> **Vector Roles:**
> * `pos` vector stores the ball's current location on the canvas (x, y).
> * `vel` vector stores the ball's speed and direction of movement (dx, dy) per frame.
> 
> 
> **Position Updating:** Every frame in the `move()` method, vector addition adds the velocity vector to the position vector (`this.pos.add(this.vel)`), which automatically shifts the ball's coordinates by its speed in both X and Y directions simultaneously.

3. Add a `move()` method that updates position: `this.pos.add(this.vel)`.
4. Add `checkWallCollisions()` to reverse direction when hitting left/right walls, and reverse vertical velocity when hitting the top wall.
5. Add an `isDead()` method returning `true` when `pos.y` goes past the bottom edge of the screen.

### Step 3: Implement Paddle Collision & Deflection Logic

**Standard Approach:**
Reverse vertical velocity on impact (`this.vel.y *= -1`).

**Advanced Approach (Variable Deflection):**
Calculate impact distance from the paddle's center using `map()` to assign a deflection angle (-60 degrees to 60 degrees).

> **Why Map the Impact Distance?**
> Simple reflection (`vel.y *= -1`) gives the player no control over where the ball goes. Mapping impact position relative to the paddle center provides directional control:
> * **Center Hit:** Deflects straight up (0 degrees)
> * **Far Left Edge Hit:** Sharp bounce to the left (-60 degrees)
> * **Far Right Edge Hit:** Sharp bounce to the right (60 degrees)
> 
> 

#### Method Logic (Advanced Angle Calculation)

1. **Find Relative Impact Point:** `let diff = ball.pos.x - paddle.pos.x;`
2. **Map to Angle:** Map `diff` from `[-paddle.w / 2, paddle.w / 2]` to `[-60, 60]` degrees.
3. **Update Velocity with Trigonometry:**
* `vel.x = speed * sin(radians(angle))`
* `vel.y = -speed * cos(radians(angle))` *(negative because upwards is negative Y in p5.js)*

4. In `sketch.js`, generate a grid of bricks in `setup()` using nested `for` loops.
