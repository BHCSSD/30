# 30.3.03.02 DEMO Level up
```
30.3.03.02 DEMO Level up
```

**Goal**

Add behavior, movement and bouncing, to the class using new **methods**. 
* Intro the concept of the **Client/Server Relationship**.

### Steps

1.  **Add the `move()` Method:**

      * Inside the `BouncingBall` class, add a method that changes the object's properties:
        ```javascript
        // ... inside the BouncingBall class ...
        move() {
          // Update the position property
          this.x += this.speedX;
        }
        ```

2.  **Add the `checkEdges()` Method:**

      * Add a method to handle the physics (the logic):
        ```javascript
        //... inside the BouncingBall class ...
        checkEdges() {
          // If the ball hits the right edge
          if (this.x + this.r > width || this.x - this.r < 0) {
            // Reverse the speed
            this.speedX *= -1;
          }
        }
        ```

3.  **Calling the Methods:**

      * In `draw()`, call the new methods for both objects:
        ```javascript
        function draw() {
          background(50);

          ballA.move();
          ballA.checkEdges();
          ballA.display();

          ballB.move();
          ballB.checkEdges();
          ballB.display();
        }
        ```
