## Overview

Create four different Object Literals, each object belongs to one quadrant of the canvas 

**Each object literal must have:**

  * At least three properties
  * One method that performs a behavior
  * A display method that draws the object
  * A call to the methods inside the draw function
  * well formatted and edited code

### Q1: 
* **Object Name: `q1`**
* **Goal:** Your object bounces left to right in the quadrant like a boring ping pong game
* **Properties:**
  * `cx`, `cy`
  * `size`
  * `color`
*  **Method:**
    * `move()`: increases `cx` by 1 each frame.
        * *Hint:* Use `if (this.x > width / 2)` to detect when it crosses the boundary.
        * [constrain](https://p5js.org/reference/p5/constrain/) is very useful

**Reminder:**
* Call `q1.move()` and `q1.display()`

### Q2:

* **Object Name: `q2`**
* **Goal:** The square stays centered in the quadrant while its size expands and shrinks.
* **Properties:**
  * `cx`, `cy`
  * `baseSize`
  * `pulsar` (a counter for pulsing)
* **Method:**
  * `pulse()`: changes the size to create a pulsating effect
    Level 1: Increase and decrease size with simple logic
    Level 2: Use `sin()` to create smoother pulsing. [Docs](https://p5js.org/reference/p5/sin/)
      * as the square shrinks and grows changes it transparency
      * `fill(r,g,b,a)` alpha (a) is the transperency 0-255

> [!TIP]
> `sin()` returns values from -1 to 1. Multiply this to control how large the size change is

### Q3:

* **Object Name: `q3`**
* **Goal:** The object flickers to a new horizontal position each frame
* **Properties:**
  * `cx`, `cy`
  * `targetX`
  * `color`

*  **Method:**
  * `shift()`: picks a new random `targetX` value inside the bottom left quadrant and jumps there instantly
    * reminder of `random` && remember that the left half of the canvas ranges from `0` to `width/2`
    * Using mod, only transport every 34 frames.

### Q4:

* **Object Name: `q4`**
* **Goal:** The object follows the mouse smoothly
* **Properties:**
  * `cx`, `cy`
  * `speed`
* **Method:**
  * `chase()`: moves the object a small amount toward the mouse position
    * You can use the formula: `this.x += (mouseX - this.x) * this.speed`

>[!TIP]
> A speed value like `0.05` moves the object 5% closer each frame
