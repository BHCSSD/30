## Goal:

* Move from using Object Literals to using a formal **Class** structure with the `class` keyword
* Understand the Constructor as the setup function for each object that gets created from the class

**Key word:**
* **CONSTRUCTOR**
*  **INSTANCE**

---

## Step 1: Define the Class Blueprint

A class is a blueprint. It describes what every object created from it should look like. The class itself is not an object.

Create a new class called `BouncingBall` outside of `setup()` and `draw()`.

```javascript
class BouncingBall {

  //constructor runs one time when a new object is created
  constructor(startX, startY, startSize, startSpeed) {

    //the object's properties
    this.x = startX
    this.y = startY
    this.r = startSize / 2
    this.speedX = startSpeed

    //each ball has a random color
    this.color = color(random(255), random(255), random(255))
  }
}
```

> [!NOTE]
> **You need to know**
> 
> * The `this` keyword refers to the specific object being created at that moment
> * Every object made from `new BouncingBall(...)` will get its own `x`, `y`, `r`, and `speedX` values
>   

---

## Step 2: Add Methods aka Behaviors

Add a method **inside the class**, after the constructor. Methods define what the object can do.

```javascript
// Inside the BouncingBall class, after the constructor:
display() {
  fill(this.color)
  noStroke()
  ellipse(this.x, this.y, this.r * 2)
}
```

> [!NOTE]
> 
> * **Methods** inside a class do not use the `function` keyword 
> * Use `this.propertyName` to access the data that belongs to the object

---

## Step 3: Create Objects (Instantiate)

Use the `new` keyword to create actual objects from the class.
* the proper way to say this is you are making new **INSTANCE**

```javascript
let ballA
let ballB

function setup() {
  createCanvas(600, 400)

  // Create actual BouncingBall objects by calling the constructor.
  ballA = new BouncingBall(100, 200, 40, 3)
  ballB = new BouncingBall(400, 150, 60, 1)

  // These are now two separate objects with separate property values.
}
```

> [!TIP]
> 
> * Each argument passed into `new BouncingBall(...)` fills in the parameters of the constructor (`startX`, `startY`, `startSize`, `startSpeed`)
> * Changing the values creates different types of balls
> 

## Step 4: Draw and Run the Objects

Call the methods in the `draw()` function to run each object’s behavior every frame.

```javascript
function draw() {
  background(50)
  ballA.display()
  ballB.display()
}
```

> [!IMPORTANT]
> `display()` does not run by itself. You must call it for each object inside the `draw()` loop.
