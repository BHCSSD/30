### **Goal**

Design a system with two interacting classes that have an **associative relationship** (one object contains or manages another).

### **Steps**

1.  **Analyze the System:**

      * **Problem:** We want a `Head` to leave a colorful `Trail`
      * This requires two classes: `Head` and `TrailSegment`
        * **Relationship:** A `Head` object **HAS** many `TrailSegment` objects. (This is **Composition**)

2.  **Design Class 1: `TrailSegment` (The Component):**

      * This class is the simple **Component**, It only knows where it is and how to fade

    ```javascript
    class TrailSegment {
      constructor(x, y, hue) {
        this.x = x
        this.y = y
        this.hue = hue
        this.life = 255 //transparency
      }

      display() {
        colorMode(HSB, 255)
        fill(this.hue, 200, 200, this.life)
        noStroke()
        ellipse(this.x, this.y, 5)
      }

      fade() {
        this.life -= 5//changes the components internal state
      }
    }
    ```

3.  **Design Class 2: `Head` (The Manager):**

      * This class is the **Manager**, it needs an array to hold the segments

    ```javascript
    class Head {
      constructor(startX, startY) {
        this.x = startX
        this.y = startY
        this.segments = [] //array to hold TrailSegment objects
        this.currentHue = 0
      }

      //Method to create and store a new segment (Factory/Initiator Role)
      createTrail() {
        // The Head (Initiator) calls the TrailSegment constructor
        let newSegment = new TrailSegment(this.x, this.y, this.currentHue)
        this.segments.push(newSegment)
        this.currentHue = (this.currentHue + 5) % 255 //cycle colours
      }

      // Method to update and display all components (Delegation Role)
      display() {
        // 1. Loop through all segments and delegate responsibilities
        for (let segment of this.segments) {
          segment.display()
          segment.fade() //Initiating the state change on the component
        }

        // 2. clean dead segment
        //this.segments = this.segments.filter(segment => segment.life > 0)
          this.elements = this.elements.filter(function (element) {
            return element.life > 0
          })
      }
      // ... (Ensure a move() method is also implemented)
    }
    ```
