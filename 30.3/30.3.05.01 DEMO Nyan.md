# 30.3.05.01 Demo Nyan

### **Goal**

Design a system with two interacting classes that have an **associative relationship** (one object contains or manages another).

### **Steps**

1.  **Analyze the System:**

      * **Problem:** We want a `Head` to leave a colorful `Trail`
      * This requires two classes: `Head` and `TrailSegment`
        * **Relationship:** A `Head` object **HAS** many `TrailSegment` objects. (This is **Composition**)

2.  **Design Class 1: `TrailSegment` (The Component):**

      * This class is the simple **Component**, It only knows where it is and how to fade

```javascript
  class TailSegment {
  constructor(x,y,hue  ){
    this.x = x
    this.y=y
    this.hue=hue
    this.life=255//transparency
  }
  
  display(){
  
    push()
    rectMode(CENTER)
    colorMode(HSB,255)
    fill(this.hue,200,200,this.life)
    noStroke()
    rect(this.x,this.y,50,33,8)
    pop()
  }
  
  fade(){
    this.life -=5
  }
```

3.  **Design Class 2: `Head` (The Manager):**

      * This class is the **Manager**, it needs an array to hold the segments

```javascript
    class Head {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.segments = []; //this holds all the tails
    this.currentHue = 255;
  }

  move() {
    this.x = mouseX;
    this.y = mouseY;
  }

  createTail() {
    let newSegment = new TailSegment(this.x, this.y, this.currentHue);
    this.segments.push(newSegment);
    this.currentHue = (this.currentHue + 5) % 255;
  }

  display() {
    //show all the tails
    for (let segment of this.segments) {
      segment.display();
      segment.fade();
    }//end of for

    for (let i = this.segments.length - 1; i >= 0; i--) {
      if (this.segments[i].life <= 0) {
        this.segments.splice(i, 1);
      }
    }//end of for

  }//end of display 
}

```
