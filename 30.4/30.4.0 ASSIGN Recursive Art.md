## Option 5: Recursive Dice *(Required for >80%)*

**TODO:** Roll recursive dice, where each pip is more dice, which has more dice for the pips

### Level 1: The Single Die: `drawDie(cx, cy, size, value)`

* **Task:** Create a single die face with `if/else` logic to place pips for values `1–6`.
* **Tip:** Avoid hard-coding pixel coordinates. Calculate pip offsets relative to `size` (e.g., the center pip is at `(cx, cy)`, while the top-left pip is at `(cx - size / 4, cy - size / 4)`).
* **Clean Code Tip:** Write a `getPipOffsets(value, size)` helper that returns an array of `[dx, dy]` pairs so you don't repeat coordinate math across levels.



### Level 2: Modular Pips: `drawPip()`

* **Task:** Refactor your pip drawing logic into a dedicated `drawPip()` function called by `drawDie()` at each pip coordinate.
* **TODO:** Render one large die containing `1–6` smaller circles positioned accurately as pips.

### Level 3: The Fractal Pip: `drawDie(cx, cy, size, value, depth)`

* **Task:** Add a `depth` parameter to `drawDie()`.
* **Base Case:** When `depth === 0`, draw a standard circular pip.
* **Recursive Step:** When `depth > 0`, draw a smaller die at each pip coordinate.

### Level 4: Randomized Sub-Dice

* **Task:** Make every recursive sub-die roll its own value. Inside the recursive call, pass `floor(random(1, 7))` as the new `value`.
* **Concept:** Every leaf in your recursion tree will now have a unique lineage while still respecting the global `depth` limit.
* **Casino Neon Aesthetic:** Style dice as dark rounded squares with neon borders color-coded by rolled `value` (1-6) for a stained-glass mosaic look.
* **Click-to-Roll Interactivity:** Use `noLoop()` in `setup()` and call `redraw()` inside `mousePressed()` so you can re-roll fresh fractal dice on click without static flickering.



> **TIP:** Call your final recursive die function inside `setup()` (or trigger it with `mousePressed()` / `noLoop()`) calling `random()` continuously inside `draw()` will cause the dice to flicker
