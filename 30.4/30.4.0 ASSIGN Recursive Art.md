**Goal:** Make an optical illusion swirl effect using nested geometry.

### Level 1: Basic Nesting `drawSquare(cx, cy, size, depth)`
* **Logic:** At each level, draw a square, then call the function again with `size * 0.8`.

### Level 2: 
* **Transformation:** Incorporate `push()`, `rotate(0.1)`, `pop()` at each recursive step.
* **Effect:** This will create a spiral nested effect as the squares shrink.

### Level 3: 
* **Visuals:** Use the `lerpColor()` function to transition the square strokes or fills from **Gold** to **Dark Purple** as the recursion depth increases.

## Option 3: The Recursive H-Tree
**Goal:** Visualize a fractal branching structure

### Level 1: Basic Branching
* **Logic:** Draw a large "H". At the four tips of the "H", recursively call the function to draw four smaller "H" shapes.

### Level 2: Depth Control
* **Variable:** Use a `depth` parameter to control the generations. At 4 levels of recursion, the pattern should resemble a complex circuit board or map.

### Level 3: Kinetic Growth
* **Interactivity:** Link the length of the "H" branches to `mouseY`. The entire structure should expand and contract based on vertical mouse movement.

## Option 4: Recursive Target
**Goal:** Master concentric shapes and conditional logic.

### Level 1: Concentric Circles
* **Logic:** Draw a large circle. Recursively draw a circle inside it that is 20 pixels smaller until the size reaches 0.

### Level 2: Alternating Logic
* **Conditional:** If the current `depth` is **even**, set the fill to black. If the `depth` is **odd**, set the fill to white.

### Level 3: The Tunnel Effect
* **Advanced Motion:** Change the horizontal offset of the inner circles based on `mouseX`.
* **Challenge:** Make a a `sin()` wave function to the offset so the "tunnel" shifts in a smooth, oscillating motion.
