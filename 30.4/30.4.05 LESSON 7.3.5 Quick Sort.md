To understand Quick Sort, we must first understand its engine: the **Partition**.

---

## 1. Main concept: Partitioning
Partitioning is a helper process that organizes a list around a specific value called the **pivot**.

* **Choose a Pivot:** By convention, we pick the **first** element of the list.
* **Divide the Rest:** Iterate through the remaining elements and split them into two groups:
    1.  **Smaller:** Elements less than or equal to the pivot.
    2.  **Greater:** Elements greater than the pivot.
* **Result:** You end up with three distinct parts: `smallerList`, `pivot`, `greaterList`

### partition([3, 2, 5, 1, 4])
1.  **Pivot:** 3
2.  **Compare others to 3:**
    * 2 is smaller: [2]
    * 5 is greater: [5]
    * 1 is smaller: [2, 1]
    * 4 is greater: [5, 4]
3.  **Return:** ([2, 1], 3, [5, 4])

```python
def partition(L):
    # L is [3, 2, 5, 1, 4]
    pivot = L[0] #pivot = 3
    smaller = [ ]
    larger = [ ]
    
    for i in range(1, len(L)): #Loop over all values after the pivot (from index 1 to the end)
        if L[i] <= pivot:
            smaller.append(L[i])
        else:
            larger.append(L[i])
            
    return smaller, pivot, larger
```

## 2. The Quick Sort Algorithm

Now that we can partition, the sorting logic becomes simple using recursion.

### The Logic
1.  **Base Case:** If a list has **0 or 1 elements**, it is already sorted. Return the list as is.
2.  **Recursive Case:**
    * **Partition** the list to get `smaller`, `pivot`, and `larger`
    * **Recursively sort** the `smaller` list
    * **Recursively sort** the `larger` list
    * **Combine**: `sorted_smaller + [pivot] + sorted_larger`


```python
def quickSort(L):
    # Base Case: Lists with 0 or 1 elements are already sorted
    if len(L) < 2:
        return L
    else:
        # Recursive Case: Partition and sort the subLists
        smaller, pivot, larger = partition(L)
        return quickSort(smaller) + [pivot] + quickSort(larger)

def partition(L):

    smaller = [ ]
    larger = [ ]

    # Loop over all values after the pivot

            larger.append(L[i])

```
