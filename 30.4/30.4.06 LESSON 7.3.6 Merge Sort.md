While Quick Sort is fast, it has a "weakness" where it slows down on already-sorted lists. 

**Merge Sort** is an alternative that is consistently fast regardless of how the input list is ordered. 
* It follows a "divide, conquer, and combine" strategy.

---

## 1. The Helper: Merging
To understand Merge Sort, you must first understand how to **merge** two lists that are *already sorted*.

### The Merging Process
Imagine you have two sorted stacks of cards. To merge them into one big sorted stack:
1.  Compare the top card of the left stack `L` with the top card of the right stack `M`
2.  Take the smaller card and place it into your new list `N`
3.  Repeat until one stack is empty, then move all remaining cards from the other stack into `N`

#### Merge L=[2, 5] and M=[1, 6]
* **Step 1:** Compare L[0] (2) and M[0] (1). 1 is smaller. N = [1].
* **Step 2:** Compare L[0] (2) and M[1] (6). 2 is smaller. N = [1, 2].
* **Step 3:** Compare L[1] (5) and M[1] (6). 5 is smaller. N = [1, 2, 5].
* **Step 4:** L is empty. Move the rest of M (6) to N. N = [1, 2, 5, 6].


```python
def merge(L, M):
    N = [] # Final List to return
    i = 0  # Index for list L
    j = 0  # Index for list M
    
    # We continue as long as there are elements left in either L or M
    while (i < len(L)) or (j < len(M)):
        if j == len(M):     # If we've used all elements in M, we must take from L
            useL = True
        elif i == len(L):  # If we've used all elements in L, we must take from M
            useL = False
        else:
            # If both have elements, compare the current items
            # Take from L if its value is smaller
            useL = (L[i] < M[j])
            
        if useL:
            N.append(L[i])
            i += 1
        else:
            N.append(M[j])
            j += 1
            
    return N
```

## 2. The Merge Sort Algorithm
With the merge helper ready, the recursive sorting logic works by breaking the list down to its smallest possible parts.

### The Logic
1.  **Base Case:** A list with 0 or 1 elements is already sorted. Return it.
2.  **Recursive Case:**
    * **Divide:** Split the unsorted list into a left half and a right half.
    * **Conquer:** Recursively call `mergeSort` on the left half and the right half.
    * **Combine:** Use the `merge` function to join the two now-sorted halves into one final sorted list.



---

## 3. The Code
```python
def mergeSort(L):
    # Base Case: Lists with 0 or 1 elements are already sorted
    if len(L) < 2:
        return L
    else:
        # Recursive Case:
        # 1. Divide the list in half
        mid = len(L) // 2
        
        # 2. Conquer: Recursively sort both halves
        sortedLeftHalf = mergeSort(L[:mid])
        sortedRightHalf = mergeSort(L[mid:])
        
        # 3. Combine: Merge the two sorted halves back together
        return merge(sortedLeftHalf, sortedRightHalf)

def merge(L, M):
    N = []
    i = j = 0  #points for L and M lists

    # Continue until we have processed every element in both lists
    while (i < len(L)) or (j < len(M)):
        if j == len(M):
            # M is empty, take from L
            useL = True
        elif i == len(L):
            # L is empty, take from M
            useL = False
        else:
            # Both lists have elements; pick the smaller one
            useL = (L[i] < M[j])


        if useL:    #bool value based on the code above
            N.append(L[i])  # Add the current value from L to our merged list
            i += 1          # Move the "pointer" forward in list L
            
        # Otherwise, the correct next value must be in list M:
        else:
            N.append(M[j])  # Add the current value from M to our merged list
            j += 1          # Move the "pointer" forward in list M
    return N

```
