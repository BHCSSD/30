### **Step 2: How Bubble Sort Works**

**Main Idea:** Bubble Sort repeatedly **compares neighboring elements** and **swaps them if they are in the wrong order**.

* Imagine the largest number "bubbling up" to its correct position at the end of the list, like air bubbles rising in water.
* After the first complete pass, the **largest element is guaranteed to be in its correct place**.
* The process is then repeated for the remaining unsorted part of the list until the entire list is sorted.

#### **Walkthrough Example**

Sorting `[5, 2, 9, 1]` in ascending order.

| Pass | List State | Comparison & Swaps | Notes |
| --- | --- | --- | --- |
| **1** | `[2, 5, 1, 9]` | (5, 2) swapped; (9, 1) swapped; 9 moved to end. | The largest element (**9**) is now correctly placed. |
| **2** | `[2, 1, 5, 9]` | (5, 1) swapped; (2, 1) swapped. | The next largest element (**5**) is now correctly placed. |
| **3** | `[1, 2, 5, 9]` | (2, 1) swapped. | List is now fully sorted. |

## **Part 2: Key Technical Details**

### **The Mechanics**

* **Adjacent Comparison:** Bubble Sort compares index  with index .
* **Swapping:** If the first item is larger than the second (for an ascending sort), they swap positions.
* **Pass Persistence:** After each pass, the largest remaining unsorted element "settles" at the end.

### **Time Complexity**

Time complexity measures how an algorithm's runtime grows as the input size increases.

* **Worst-case:  (Quadratic Time)**
  * Occurs if the list is in **reverse order**.
  * If the list size doubles, the runtime increases by **four times**. Every element must be compared and swapped on every pass.


* **Best-case:  (Linear Time)**
  * Occurs if the list is **already sorted**.
  * If optimized, the algorithm only needs **one pass** to confirm no swaps are needed before stopping.



> [!CAUTION]
> **Implementation Tip: Nested Loops**
> To implement Bubble Sort, you will need **two nested loops**:
> 1. **Outer Loop:** Controls the number of passes. Since  passes are enough to sort  elements, this loop runs  times.
> 2. **Inner Loop:** Handles the comparisons and swaps within a single pass. It iterates only over the unsorted part of the list.

  <details>
  <summary>ANSWER</summary>

  </details>

* **2. What does Bubble Sort compare during its process?**
  <details>
  <summary>ANSWER</summary>
  It compares **neighboring elements** (adjacent items) and swaps them if they are in the wrong order.
  </details>

* **3. When can Bubble Sort finish early?**
  <details>
  <summary>ANSWER</summary>
