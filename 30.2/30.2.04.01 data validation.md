## Method 1: Using `try...except` (Recommended for Numbers)

Attempt to convert the string returned by `input()` into your desired type (`int`, `float`, etc.). 
- If the conversion fails, Python raises a `ValueError`, which you catch to display an error message and re-prompt.

```python
while True:
    try:
        userInput = int(input("Enter your age (integer): "))
        break  # Exit loop if conversion succeeds
    except ValueError: ##built in
        print("Invalid input. Please enter a valid integer.\n")



```

### Method 2: Using String Methods (For Specific Text Patterns)

For checking specific character types without converting, use built-in string methods like `.isdigit()` or `.isalpha()`

```python
# check that input contains digits only
while True:
    userInput = input("Enter your ZIP code (digits only): ")
    if userInput.isdigit():  
        zipCode = int(userInput)
        break
    print("Invalid entry. Please enter numbers only.\n")


```


1. **`while True`** makes an endless loop that continuously prompts the user
2. **`try` block** runs code that might raise an error (like `int("abc")`)
3. **`except ValueError`** catches type-conversion failures and prevents the program from crashing
4. **`break`** terminates the loop immediately once valid input is received.
