## Level 1: Data Setup and Basic Sorting 

### Setup

1.  **Data Structure:** Use Parallel Lists for track metadata. Each index $i$ across the lists represents a single song record:

      * `Titles` (String)
      * `Artists` (String)
      * `Durations` (Integer, seconds)

2.  **Playlists:** Create two lists of 10 tracks each:

      * **Playlist A (Road Trip Mix):** Initially sorted by **Title**.
      * **Playlist B (Workout Mix):** Initially sorted by **Duration**.

    ```python
    # Titles must be alphabetically sorted in this example.
    A_Titles = [
        "Come Away With Me",  # C
        "Hotel California",   # H
        "Lovely Day",         # L
        "Take It Easy"        # T
    ]
    A_Artists = [
        "Norah Jones",
        "The Eagles",
        "Bill Withers",
        "The Eagles"
    ]
    A_Durations = [
        178, # 2:58
        391, # 6:31
        247, # 4:07
        207  # 3:27
    ]

    # Durations must be numerically sorted in this example.
    B_Titles = [
        "Pump Up The Jam",    # 209s
        "Don't Stop Me Now",  # 215s
        "Eye of the Tiger",   # 245s
        "Lose Yourself"       # 326s
    ]
    B_Artists = [
        "Technotronic",
        "Queen",
        "Survivor",
        "Eminem"
    ]
    B_Durations = [
        209,
        215,
        245,
        326
    ]

    ```



### Function Required

#### 1 Sort Function: Sort by Artist (Insertion or Selection Sort)

  * **Function:** `sort_by_artist(title_list, artist_list, duration_list)`
  * Implement **Insertion Sort** or **Selection Sort** to sort the parallel lists based on the `Artist` list.
  * **IMPORTANT:** When swapping elements in the `artist_list`, you **must swap the corresponding elements in the `title_list` and `duration_list`** to keep the records synchronized.

### Testing and Output (Level 1)

  * Display Playlist A before and after sorting it by **Artist**.

## Level 2: Merging and Max Search 

### Functions Required

#### 2 Merge Function: Combine Playlists (Concatenate and Sort)

  * **Function:** `merge_playlists(A_Lists, B_Lists)`
      1.  Perform a **simple concatenation** (`.extend()`) to combine all parallel lists from Playlist A and Playlist B into three new, master lists.
    2.  Call your Level 1 `sort_by_artist` function on the resulting master lists.
  * **Return:** The three final, synchronized, parallel lists, all sorted by **Artist**.

#### 3 Max Search Function: Find Longest Track

  * **Function:** `find_longest_track(duration_list, title_list)`
  * **Requirement:** Traverse the `duration_list` to find the single largest track duration.
  * **Return:** The title and duration of the longest track as a tuple.

### Testing and Output (Level 2)

  * Display the final merged playlist (first 10 records).
  * Display the result of `find_longest_track` on the merged playlist.

## Level 3: Efficient Searching

### Functions Required

#### 4 Search Function: Find by Duration (Binary Search)

  * **Function:** `binary_search_duration(duration_list, title_list, artist_list, target_duration)`
  * **Requirement:** Implement the **Binary Search** algorithm on the `duration_list` to find the target track.
  * **Process:**
    1.  Use the master lists created in Level 2.
    2.  Before running the search, you must **re-sort the master lists by Duration** using your Level 1 sort logic.
  * **Return:** A tuple containing the song's title and artist, or `None` if the track is not found.
