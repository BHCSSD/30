## **Part 1: Smaller Data Set and Basic Search (60%)**

Binary search only works if data is sorted. For this assignment, you will manually provide pre-sorted data.

### **Requirements**

* **Encapsulation:** No code is allowed outside of functions. All logic must reside within `binarySearch`, `main`, or your `test` function.
* **The List:** Create an alphabetical string list called `creatures` with **5 sea creatures**.
    * *Example:* `["clam", "dolphin", "eel", "orca", "turtle"]` (Do not use these specific examples).
    * Your list **must** be significantly different from your classmates'.


* **Parallel Data:** Create a parallel list called `categories` that classifies each creature (e.g. Fish, Mammal, Mollusk).

> [!NOTE]
> **Reminder: Parallel Lists**
> Parallel lists are linked by their index. `creatures[i]` and `categories[i]` must refer to the same animal. Keep them the same length and aligned perfectly.

### **Steps (Inside `main`)**

1. **Print** the `creatures` list so the user knows the available options.
2. **Prompt** the user to enter a sea creature.
3. **Search** using your `binarySearch` function.
4. **If Found:** Print the creature and its category using the correct indefinite article (**"A"** vs **"An"**).

**Example Output:**

```text
I found it. An eel is a fish.

```

> [!TIP]
> **Grammar Logic (A vs. An):**
> Use `if creature[0].lower() in "aeiou":` to determine which article to use. Use **f-strings** for clean output: `print(f"An {name} is a {category}.")`
