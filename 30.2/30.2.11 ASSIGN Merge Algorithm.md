> [!NOTE]
> In Python, you specify data types for function parameters and return values using **type hints** 
>
> ### Basic Syntax
> Use a colon `:` after the parameter name, followed by the data type:
> ```python
> def greet(name: str, age: int, is_member: bool):
>     print(f"Hello {name}, you are {age} years old.")
> ```
>
> ### Specifying Return Types
> You can indicate what data type the function returns using `->`:
> ```python
> def add_numbers(x: float, y: float) -> float:
>     return x + y
> ```
>
> ### Common Type Hinting Patterns
>
> #### 1. Default Parameters
> If a parameter has a default value, place the value after the type hint:
> ```python
> def power(base: float, exponent: int = 2) -> float:
>     return base ** exponent
> ```
>
> #### 2. Optional or Multiple Types
> Use `|` to allow multiple accepted types, or `None`:
> ```python
> def find_user(user_id: int | str) -> dict | None:
>     # user_id can be int OR str
>     # returns a dict OR None
>     pass
> ```
>
> ---
>
> ### Important Note: Python is Dynamically Typed
> Type hints in Python are **informational, not enforced at runtime**. Python won't raise an error automatically if you pass an integer into a parameter hinted as `str`:
> ```python
> # Python executes this without throwing a type error:
> greet(123, "thirty", "yes")
> ```
