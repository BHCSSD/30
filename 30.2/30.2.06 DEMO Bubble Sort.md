### **Step 2: Code Bubble Sort**

Implement the core logic for the Bubble Sort algorithm inside the `bubble_sort(arr)` function. Follow these logic steps:

1. **Find the length** of the list:
`n = len(arr)`
2. **Start an Outer Loop** (Pass Control):
`for i in range(n - 1):`
> [!NOTE]
> **Outer Loop Explanation**
> We use `n - 1` passes because after the  pass, the smallest remaining element is guaranteed to be in its correct place. The **final element automatically falls into place**.


3. **Start an Inner Loop** (Comparison and Swap):
`for j in range(n - 1 - i):`
> [!TIP]
> **Inner Loop Optimization**
> We subtract `i` from `n - 1` because after each pass `i`, the largest element has "bubbled up" to the end. We avoid re-checking elements that are already sorted, making the algorithm more efficient.


4. **Compare and Swap**:
* Compare `arr[j]` with `arr[j + 1]`.
* If `arr[j] > arr[j + 1]`, they are **out of order** for an ascending sort.
* Use Python's **multiple assignment** to swap them in one line:
`arr[j], arr[j + 1] = arr[j + 1], arr[j]`

    L3 = [5, 4, 3, 2, 1]
    bubble_sort(L3)
    assert L3 == [1, 2, 3, 4, 5]

    # Case 4: Edge Case - Empty list
    L4 = []
    bubble_sort(L4)
    assert L4 == []
