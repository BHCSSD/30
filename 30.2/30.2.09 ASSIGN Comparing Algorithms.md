### Step 2: Handle List Mutability

Sorting algorithms **change (mutate)** the lists they are called on. Reusing a sorted list for a subsequent sort test will skew your results.

> [\!CAUTION]
> **Critical Mutation Warning:**
> When testing multiple algorithms, never reuse a list that has already been sorted\!Always make a fresh copy using `copy.copy()` before each test.

Use Python's `copy` module:

```python
import copy
import time

# 1. Create original master list once
master_list = [1000 items]

# 2. Before testing Bubble Sort:
list_for_bubble = copy.copy(master_list)
start = time.perf_counter()
bubble_sort(list_for_bubble)
# ... end timing

# 3. Before testing Insertion Sort:
list_for_insertion = copy.copy(master_list)
start = time.perf_counter()
insertionSort(list_for_insertion)
# ... end timing
```
