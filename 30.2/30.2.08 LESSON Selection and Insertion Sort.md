    ```python
    def selectionSort(arr):
        """
        Sorts the list in ascending order using the Selection Sort algorithm.
        Finds the minimum element from the unsorted part and puts it at the beginning.
        """
        n = len(arr)
        # Outer loop iterates through all elements of the array
        for i in range(n):
            # Assume the current position 'i' holds the minimum value
            min_index = i
            
            # Inner loop finds the actual minimum element in the remaining unsorted array
            for j in range(i + 1, n):
                if arr[j] < arr[min_index]:
                    min_index = j
            
            # Swap the found minimum element with the element at the current position 'i'
            arr[i], arr[min_index] = arr[min_index], arr[i]
    ```
### **A. Selection Sort Code Analysis**

*The strategy: Find the smallest thing in the messy pile and move it to the front.*

| Code Line | Explanation (What is this line doing?) |
| --- | --- |
| `for i in range(len(arr)):` | **Outer Loop:** Moves the "boundary" between the sorted and unsorted parts of the list. |
| `min_index = i` | **Initialization:** Assumes the first unsorted item is the smallest until proven otherwise. |
| `for j in range(i + 1, len(arr)):` | **Inner Loop:** Scans the rest of the list to look for a smaller number. |
| `if arr[j] < arr[min_index]:` | **Comparison:** Checks if the current item being scanned is smaller than our current "best find." |
| `min_index = j` | **Update:** Remembers the location (index) of the new smallest number found. |
| `arr[i], arr[min_index] = arr[min_index], arr[i]` | **Swap:** Takes the smallest number found and swaps it into its correct sorted spot. |





### Step 2: Insertion Sort

1.  **Watch:** [Insertion Sort Explained](https://youtu.be/R_wDA-PmGE4?si=LxmQx434vz3U5fh1)

2.  **Add the Function:** Add the following function to your toolkit file.

    ```python
    def insertionSort(arr):
        """
        Sorts the list in ascending order using the Insertion Sort algorithm.
        Builds the final sorted array one item at a time by inserting elements
        into their correct position in the already sorted section.
        """
        n = len(arr)
        # Loop starts from the second element (index 1)
        for i in range(1, n):
            # 'key' is the element to be inserted into the sorted sub-array
            key = arr[i]
            # 'j' is the index of the last element in the sorted sub-array
            j = i - 1
            
            # Move elements of the sorted sub-array that are greater than 'key'
            # one position ahead of their current position
            while j >= 0 and arr[j] > key:
                arr[j + 1] = arr[j]
                j -= 1
            
            # Insert the 'key' into its correct position
            arr[j + 1] = key
    ```
### **B. Insertion Sort Code Analysis**

*The strategy: Pick up one item at a time and "slide" it into its correct place in the sorted section.*

| Code Line | Explanation (What is this line doing?) |
| --- | --- |
| `for i in range(1, len(arr)):` | **Outer Loop:** Starts at the second item and picks up each item one by one to "insert" it. |
| `key = arr[i]` | **Store Value:** Holds the current item in a temporary variable so it doesn't get lost during shifting. |
| `j = i - 1` | **Set Pointer:** Looks at the item immediately to the left to begin comparing backward. |
| `while j >= 0 and arr[j] > key:` | **Inner Loop/Condition:** Keeps looking left as long as the items are larger than our "key" value. |
| `arr[j + 1] = arr[j]` | **Shift:** Slides the larger item one spot to the right to make a "hole" for the key. |
| `j -= 1` | **Decrement:** Moves the pointer one more step to the left to check the next item. |
| `arr[j + 1] = key` | **Insert:** Once the correct spot is found, "drops" the key value into the hole. |

> [!TIP]
> **Testing Reminder:**
> Both algorithms sort the list in place (they mutate ify the original array and do not return a new one). You can test them by running a test function with asserts or by printing your list before and after the sort to visually confirm the difference.
