## Understanding Merge Algorithms

Merging two lists is a common task in computer programming, often required when integrating data from multiple sources 
* e.g. combining sorted results from different files or merging live data feeds

-----

### Two Types of Merging

### 1\. Concatenating (Appending) aka smooshing togeather

  * This is the simplest form of merging.
  * You take all elements from one list and place them directly at the end of another list.
  * This method works regardless of whether the initial lists are sorted.

```python
list1 = [1, 2, 3]
list2 = [4, 5, 6]
merged = list1 + list2
# merged = [1, 2, 3, 4, 5, 6]
```

### 2\. Interweaving (Merging Two Sorted Lists)

  * This more advanced method combines **two lists that are ALREADY sorted** into a single, combined sorted list.
  * The algorithm works by **comparing the smallest remaining items** (the items at the front of each list) and adding the smaller one to the new merged list.
  * This efficient process continues until both lists are completely moved into the final merged list.

#### Step-by-Step Algorithm Breakdown

The core process of interweaving involves iteratively taking the smallest available element from the *start* of the two input lists.

**Marging:**
* List A: `[1, 4, 7]`
* List B: `[2, 3, 6, 8]`
* Result List: `[]`

| Step | List A (Remaining) | List B (Remaining) | Comparison | Action | Result List |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **0** | `[1, 4, 7]` | `[2, 3, 6, 8]` | Compare 1 and 2 | Add 1 from A | `[1]` |
| **1** | `[4, 7]` | `[2, 3, 6, 8]` | Compare 4 and 2 | Add 2 from B | `[1, 2]` |
| **2** | `[4, 7]` | `[3, 6, 8]` | Compare 4 and 3 | Add 3 from B | `[1, 2, 3]` |
| **3** | `[4, 7]` | `[6, 8]` | Compare 4 and 6 | Add 4 from A | `[1, 2, 3, 4]` |
| **4** | `[7]` | `[6, 8]` | Compare 7 and 6 | Add 6 from B | `[1, 2, 3, 4, 6]` |
| **5** | `[7]` | `[8]` | Compare 7 and 8 | Add 7 from A | `[1, 2, 3, 4, 6, 7]` |
| **6** | `[]` | `[8]` | A is empty | Add remaining 8 from B | `[1, 2, 3, 4, 6, 7, 8]` |

**Final Merged List: `[1, 2, 3, 4, 6, 7, 8]`**

-----

> [!CAUTION]
>
> ### A Word of Warning: MergeSort vs. Merge
>
> Be careful **not to confuse** the process of merging two sorted lists with the complex **MergeSort algorithm**.
>
>   * **MergeSort** is a recursive sorting method that splits a single **unsorted** list, sorts the halves, and then merges them back together.
>   * The process you are studying is simply merging **already sorted lists**.
>     * **You are not implementing MergeSort**


## Code 
```python
def merge(list1, list2):
    """
    Interweaves two sorted lists into a single sorted list.
    
    Parameters:
     list1 (list): The first pre-sorted input list.
     list2 (list): The second pre-sorted input list.
                         
    Returns:
     list: A new sorted list containing all elements from both inputs.
    """
    merged_list = []

    # Create shallow copies to avoid mutating the original lists
    Arr1 = list1[:]
    Arr2 = list2[:]

    while True:
        # Case 1: Both lists still have elements to compare
        if Arr1 and Arr2:
            # Compare the first elements of each list
            if Arr1[0] <= Arr2[0]:
                merged_list.append(Arr1.pop(0))
            else:
                merged_list.append(Arr2.pop(0))
        
        # Case 2: Only list1 has elements left
        elif Arr1:
            # List 2 is empty, dump the rest of List 1
            merged_list.extend(Arr1)
            break
        
        # Case 3: Only list2 has elements left
        elif Arr2:
            # List 1 is empty, dump the rest of List 2
            merged_list.extend(Arr2)
            break
        
        # Case 4: Both lists are empty
        else:
            break

    return merged_list

```

---

## Breakdown

### 1. `while True`

Unlike a `for` loop, where we iterate a set number of times, the `while True` loop is used because we don't know which list will empty first. The loop runs indefinitely until one of the "Case" blocks triggers a `break` command to exit.

### 2. Efficiency Note: `.pop(0)`

`list.pop(0)` removes the first element, but it forces every other element in the list to shift one index to the left. This makes it an $O(n)$ operation. While this is easy to read, for very large lists, developers often use **index pointers** (like `i` and `j`) to track position without shifting data in memory.

### 3. Handling the "Leftovers"

The most important part of the logic is what happens when one list runs out. Because the input lists are pre-sorted, if `Arr2` is empty, every remaining item in `Arr1` is guaranteed to be larger than what is already in `merged_list`. We use `.extend()` to efficiently "dump" these remaining items at once.
