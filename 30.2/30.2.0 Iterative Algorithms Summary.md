# Review and some new concepts

## 1. Lists

### A. Creation and Access

| Operation | Description | Example |
| :--- | :--- | :--- |
| **Creation** | Define lists using square brackets. | `numbers = [5, 2, 9, 1, 7]` |
| **Access** | Retrieve an item using its index (position). | `first = numbers[0]` **# 5** |
| **Negative Index** | Access elements from the end of the list. | `last = numbers[-1]` **# 7** |

### B. Slicing Lists (Extracting Subsets)

Slicing creates a new list from a segment of the original list. Slicing uses the format `[start:stop:step]`.

```python
numbers = [5, 2, 9, 1, 7, 6]

sublist1 = numbers[1:4]     # [2, 9, 1] (elements at index 1, 2, 3)
sublist2 = numbers[:3]      # [5, 2, 9] (first three elements)
sublist3 = numbers[2:]      # [9, 1, 7, 6] (from index 2 to end)
sublist4 = numbers[:]       # Copy of whole list
sublist5 = numbers[::2]     # [5, 9, 7] (every other element)
sublist6 = numbers[::-1]    # [6, 7, 1, 9, 2, 5] (reversed list)
```

### C. Mutating: Modifying and Adding Elements

| Operation | Syntax | Description |
| :--- | :--- | :--- |
| **Modification** | Change value at a specific index. | `numbers[2] = 10` |
| **`.append()`** | Adds a **single item** to the end. | `numbers.append(12)` |
| **`.extend()`** | Adds **multiple items** (from another iterable) to the end. | `numbers.extend([13, 14])` |
| **`.insert()`** | Insert an item at a specific position. | `numbers.insert(1, 8)` |

### D. Removing Elements

| Operation | Syntax | Description |
| :--- | :--- | :--- |
| **`.pop()`** | Removes and returns the **last element**. | `numbers.pop()` |
| **`.pop(index)`** | Removes and returns the item at the specified **index**. | `numbers.pop(1)` |
| **`.remove(value)`**| Removes the **first occurrence** of the specified value. | `numbers.remove(9)` |

### E. Membership Check

The `in` keyword is important for searching algorithms, checking if an item exists within a list, string, or dictionary keys.

```python
if 5 in numbers:
    print("Found it!")
```

> [!TIP]
> **`in` and `not in`**
>
>   * **`in`** checks if an item exists in a list, string, tuple, set, or dictionary keys.
>   * **`not in`** checks if it does **not exist**.
>
> <!-- end list -->
> ```python
> fruits = ["apple", "banana", "cherry"]
>
> print("banana" in fruits)     # True
> print("orange" not in fruits) # True
> ```

## 2. Loops: Iteration and Repetition

### A. The `for` Loop

Use `for` when you know the number of repetitions (e.g. iterating over a list or a range).

| Style | Description | Example |
| :--- | :--- | :--- |
| **FOR EACH: Loops Over Elements** | Simpler way to access values directly. | `for num in numbers: print(num)` |
| **Over Indices** | Necessary when you need to **modify** the list or use the index position. | `for i in range(len(numbers)): print(numbers[i])` |

### B. The `while` Loop

Use `while` when you want to repeat code **until a specific condition is met**

```python
i = 0

while i < len(numbers):
    # This loop repeats as long as 'i' is less than the list length.
    print(numbers[i])
    i += 1  # Important: Must manually increment the counter!
```

## 3. Core Algorithmic Operations IMPORTANT !!!!!!i!

### A. Swapping Elements

The fastest way to exchange the values of two variables (or list elements) is using Python's tuple assignment. This is fundamental to all exchange-based sorting algorithms

```python
numbers = [1,2,3,4,5,6,7,8]
# i = 1
# j = 3
# Swap the elements at index i and index j
numbers[i], numbers[j] = numbers[j], numbers[i]

x = 10
y = 22
x, y = y, x

```

### B. Counters / Accumulators

Variables used to track running totals or frequency counts within an iteration.

```python
count = 0
total_sum = 0
for num in numbers:
    if num > 5:
        count += 1
    total_sum += num
```

### C. Nested Loops

A loop inside another loop. Essential for comparing every possible pair of elements in a list

```python
# Compares every pair (i, j) where j is always ahead of i
for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        if numbers[i] > numbers[j]:
            # Found a pair out of order!
            print(f"Swap needed: {numbers[i]} and {numbers[j]}")
```

### D. Randomization

The `random` [module](https://www.w3schools.com/python/module_random.asp) is used for shuffling lists or generating test data.

```python
import random

# Shuffles a list in-place (used for generating random starting data)
random.shuffle(numbers)

# Generates a random integer between 1 and 100 (inclusive)
rand_num = random.randint(1, 100)
```

### E. Debugging and Output

Print variables and indices inside loops to trace how your algorithm is manipulating the data step-by-step.

```python
# Trace the current state of variables inside a loop
print("Current State:", numbers)
print("Index i:", i, " | Value:", numbers[i])
```
